# experimental-sbx

An experiment in using [Docker Sandboxes](https://docs.docker.com/ai/sandboxes/) (`sbx`) and GitHub issues so Claude can plan and implement issues automatically, gated by labels.

Work in progress. See the [design](docs/superpowers/specs/2026-11-09-ai-issue-pipeline-design.md) and [plan](docs/superpowers/plans/2026-11-09-ai-issue-pipeline.md).
